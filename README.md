# Ivy Warehouse Design Tool

Concept-stage warehouse design: size and cost racking, conveyors, AS/RS, AutoStore, ACRs, AMRs and sortation, manual vs automated, with layouts, recommendations, ROI and regional cost benchmarks.

- **Web app:** https://sleigh24-star.github.io/rackright/ (`index.html`; rates come from `rates.json` once the admin publishes it)
- **Android app:** built by **Actions → Build Android**; test APK under **Releases**
